# 🦸‍♂️ Heroes SPA 🦸‍♀️

¡Bienvenido a **Heroes SPA**! 🚀 Esta es una aplicación de una sola página (SPA) desarrollada en **React** que te permite explorar y buscar héroes de DC Comics y Marvel Comics. 🦸‍♂️🦸‍♀️

## 🌟 Características

- 🔐 **Autenticación**: Sistema de login y logout con manejo de rutas privadas y públicas.
- 🔍 **Búsqueda de héroes**: Encuentra a tus héroes favoritos utilizando el buscador.
- 🦸‍♂️ **Exploración por editoriales**: Navega entre héroes de DC Comics y Marvel Comics.
- 📄 **Detalles de héroes**: Consulta información detallada de cada héroe.
- 📂 **Persistencia de sesión**: Guarda la última ruta visitada para mejorar la experiencia del usuario.

## 🛠️ Tecnologías utilizadas

- ⚛️ **React**: Biblioteca principal para construir la interfaz de usuario.
- 🌐 **React Router DOM**: Manejo de rutas dinámicas y navegación.
- 📦 **Context API**: Gestión del estado global de la aplicación.
- 🎨 **Bootstrap**: Estilos y diseño responsivo.
- ✨ **Animate.css**: Animaciones para una experiencia visual atractiva.

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/heroes-spa.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd 07-heroes-spa
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```
5. Abre tu navegador en [http://localhost:3000](http://localhost:3000) para ver la aplicación en acción. 🌟
